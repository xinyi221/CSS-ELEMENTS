Flexbox (Alineació, Grow, Wrap i Align-Self)

📘 Teoria i Instruccions

  • 6.1 Centratge i Gap: A .flex-exemple-1, activa Flexbox (display: flex), alinea els elements al centre (justify-content: center, align-items: center) i afegeix una separació de 15px (gap: 15px).
  • 6.2 Space-Between i Flex-Grow: A .flex-exemple-2, activa Flexbox amb justify-content: space-between. Fes que l'element .flex-grow-item s'expandeixi (flex-grow: 1).
  • 6.3 Flex-Direction & Flex-Wrap: A .flex-exemple-3, activa Flexbox en direcció columna (flex-direction: column) i alinea els elements al final de l'eix secundari (align-items: flex-end). A .flex-wrap-container activa l'embolicat automàtic de linies (flex-wrap: wrap) amb un gap: 10px.
  • 6.4 Align-Self: A .flex-exemple-4 (contenidor amb align-items: flex-start i alçada fixa 100px), alinea únicament l'element .align-self-item al centre verticalment (align-self: center).

07

CSS Grid (1D, Multifila i Template Areas)

📘 Teoria i Instruccions

  • 7.1 Graella bàsica: Aplica display: grid a .grid-exemple-1 amb 3 columnes de la mateixa mida (grid-template-columns: repeat(3, 1fr)) i gap: 10px.
  • 7.2 Grid Spanning: A .grid-exemple-2, defineix grid-template-columns: 200px 1fr. Fes que .grid-header ocupi totes les columnes amb grid-column: 1 / -1.
  • 7.3 Graella Multifila (Rows & Columns): Aplica display: grid a .grid-multifila. Defineix 3 columnes (repeat(3, 1fr)) i 2 files amb alçades específiques: 60px per a la primera fila i 100px per a la segona (grid-template-rows: 60px 100px). Defineix un gap: 10px.
  • 7.4 Layout amb Grid Template Areas: A .grid-areas-layout configura un disseny de 2 columnes (150px 1fr) i 3 files (auto 1fr auto) usant grid-template-areas:
    "header header"
    "sidebar main"
    "footer footer"
    Assigna a cada un dels fills (.g-header, .g-sidebar, .g-main, .g-footer) la seva corresponent grid-area.
